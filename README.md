# Bybit Telegram Signals

Telegram-бот публикует технические сигналы по USDT perpetual-контрактам Bybit. Он читает только публичные рыночные данные, не принимает и не исполняет ордера и не требует API-ключей Bybit. Плечо не предлагается.

По умолчанию бот автоматически загружает все активные USDT perpetual-контракты Bybit и обновляет список раз в час. Перечень можно ограничить через `SYMBOLS`.

## Как работает стратегия

- Раз в `SCAN_INTERVAL_SECONDS` бот загружает свечи указанного таймфрейма из публичного Bybit API.
- Запросы для рынков ограничены по частоте; полный проход по всем контрактам может занимать больше минуты.
- Используется только последняя полностью закрытая свеча.
- Сигнал появляется при пересечении EMA 20 и EMA 50, подтвержденном RSI 14: для LONG RSI должен быть от 50 до 70, для SHORT — от 30 до 50.
- Стоп рассчитывается на расстоянии 1.5 ATR(14), тейки — на 1R и 2R. Это пример технического расчета, а не рекомендация к сделке.
- Один и тот же сигнал для свечи не отправляется повторно после перезапуска.

## Запуск

Нужен Python 3.9 или новее и токен Telegram-бота, созданного через [@BotFather](https://t.me/BotFather). Ключи Bybit не нужны.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="токен-от-BotFather"
python bot.py
```

Для Windows PowerShell используйте `$env:TELEGRAM_BOT_TOKEN="токен-от-BotFather"`.

Параметры задаются переменными окружения:

| Переменная | По умолчанию | Описание |
|---|---:|---|
| `TELEGRAM_BOT_TOKEN` | — | Обязательный токен Telegram-бота |
| `SYMBOLS` | `ALL` | `ALL` отслеживает все активные USDT perpetual-символы; можно указать список, например `BTCUSDT,ETHUSDT` |
| `INTERVAL` | `15` | Таймфрейм Bybit: `1`, `3`, `5`, `15`, `30`, `60`, `120`, `240`, `360`, `720`, `D`, `W` или `M` |
| `SCAN_INTERVAL_SECONDS` | `60` | Интервал проверки рынка, минимум 30 секунд |
| `DATABASE_PATH` | `signals.sqlite3` | Файл SQLite с подписчиками и обработанными свечами |
| `FAST_EMA_PERIOD` / `SLOW_EMA_PERIOD` | `20` / `50` | Периоды быстрой и медленной EMA; быстрая должна быть меньше медленной |
| `RSI_PERIOD` / `ATR_PERIOD` | `14` / `14` | Периоды индикаторов RSI и ATR |
| `ATR_MULTIPLIER` | `1.5` | Расстояние стопа в ATR |
| `TAKE_PROFIT_1_R` / `TAKE_PROFIT_2_R` | `1` / `2` | Уровни тейков в единицах риска; второй должен быть выше первого |

После запуска откройте бота в Telegram и отправьте `/start`. Команды: `/help`, `/status`, `/symbols`, `/stop`. Бот отправляет сигналы подписавшимся чатам; добавьте его в группу и вызовите там `/start`, чтобы получать сигналы в группе.

