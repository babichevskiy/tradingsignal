# Bybit Telegram Signals

Telegram-бот публикует технические сигналы по USDT perpetual-контрактам Bybit. Он читает только публичные рыночные данные, не принимает и не исполняет ордера и не требует API-ключей Bybit. Плечо не предлагается.

По умолчанию бот автоматически загружает все активные USDT perpetual-контракты Bybit и обновляет список раз в час. Перечень можно ограничить через `SYMBOLS`. Для сигналов бот использует публичный WebSocket Bybit: анализирует закрытую свечу сразу после ее получения, без периодического опроса каждого рынка.

## Как работает стратегия

- При запуске бот загружает начальную историю свечей из публичного REST API, затем получает обновления через публичный WebSocket Bybit. Ключи API не нужны.
- Анализ выполняется только после закрытия свечи выбранного таймфрейма; это не опрос по секундам и сигнал не может появиться до закрытия свечи.
- При разрыве соединения бот автоматически переподключается. Список активных рынков обновляется раз в час.
- Используется только последняя полностью закрытая свеча.
- Время сигналов, RSI-уведомлений, команды `/status` и системного планировщика показывается по Москве (МСК, UTC+3); временные метки свечей для расчетов остаются в UTC.
- Сигнал появляется при пересечении EMA 20 и EMA 50 с подтверждением RSI 14: для LONG RSI от 50 до 70, для SHORT от 30 до 50. Дополнительно LONG разрешен, только если закрытие свечи `TREND_INTERVAL` выше EMA `TREND_EMA_PERIOD`; SHORT — если ниже.
- Объем закрытой сигнальной свечи должен быть не меньше чем в 1.2 раза среднего объема предыдущих 20 свечей. Оба фильтра тренда и объема настраиваются переменными окружения.
- Отдельно бот сообщает, когда RSI 14 впервые входит в зону перекупленности (≥70) или перепроданности (≤30) на закрытой свече. Сообщение предупреждает о возможном откате/отскоке, но не гарантирует разворот и не заменяет сигнал со стопом/тейками.
- RSI-предупреждение отправляется только при входе в экстремальную зону; пока RSI остается в ней, повторных сообщений нет. После выхода из зоны новое вхождение может вызвать новый алерт.
- Стоп рассчитывается на расстоянии 1.5 ATR(14), тейки — на 1R и 2R. Это пример технического расчета, а не рекомендация к сделке.
- Один и тот же сигнал для свечи не отправляется повторно после перезапуска.

## Запуск

Нужен Python 3.9 или новее и токен Telegram-бота, созданного через [@BotFather](https://t.me/BotFather). Ключи Bybit не нужны.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="токен-от-BotFather"
python bot.py
```

Для Windows PowerShell используйте `$env:TELEGRAM_BOT_TOKEN="токен-от-BotFather"`.

Параметры задаются переменными окружения:

| Переменная | По умолчанию | Описание |
|---|---:|---|
| `TELEGRAM_BOT_TOKEN` | — | Обязательный токен Telegram-бота |
| `SYMBOLS` | `ALL` | `ALL` отслеживает все активные USDT perpetual-символы; можно указать список, например `BTCUSDT,ETHUSDT` |
| `INTERVAL` | `15` | Таймфрейм Bybit: `1`, `3`, `5`, `15`, `30`, `60`, `120`, `240`, `360`, `720`, `D`, `W` или `M` |
| `DATABASE_PATH` | `signals.sqlite3` | Файл SQLite с подписчиками и обработанными свечами |
| `FAST_EMA_PERIOD` / `SLOW_EMA_PERIOD` | `20` / `50` | Периоды быстрой и медленной EMA; быстрая должна быть меньше медленной |
| `RSI_PERIOD` / `ATR_PERIOD` | `14` / `14` | Периоды индикаторов RSI и ATR |
| `ATR_MULTIPLIER` | `1.5` | Расстояние стопа в ATR |
| `TAKE_PROFIT_1_R` / `TAKE_PROFIT_2_R` | `1` / `2` | Уровни тейков в единицах риска; второй должен быть выше первого |
| `TREND_INTERVAL` / `TREND_EMA_PERIOD` | `60` / `200` | Таймфрейм и период EMA фильтра направления тренда |
| `VOLUME_MULTIPLIER` / `VOLUME_LOOKBACK` | `1.2` / `20` | Минимальный объем сигнальной свечи относительно среднего объема предыдущих свечей |

После запуска откройте бота в Telegram и отправьте `/start`. Команды: `/help`, `/status`, `/symbols`, `/stop`. Команда `/status` показывает состояние потока. Бот отправляет сигналы подписавшимся чатам; добавьте его в группу и вызовите там `/start`, чтобы получать сигналы в группе.

## Историческая проверка фильтров

Скрипт сравнивает текущий фильтр с вариантами EMA 200/300 и объема 1.2x/1.5x/2.0x. Для отбора использует первые 2/3 периода, а оставшуюся 1/3 — как проверочную выборку. Рекомендация строгого фильтра появляется только при не менее 200 разрешенных TP1/стоп исходах и улучшении доли TP1 минимум на 2 процентных пункта на проверочной выборке; скрипт не меняет настройки бота автоматически.

```bash
python backtest.py --symbols ALL --days 30
```

Для более быстрой проверки на 150 наиболее торгуемых рынках: `python backtest.py --symbols ALL --top-by-turnover 150 --days 30`.

Для быстрой проверки на трех крупных рынках: `python backtest.py --symbols BTCUSDT,ETHUSDT,SOLUSDT --days 30`. Скрипт проверяет достижение первого тейка или стопа в течение 24 часов после сигнала; касание тейка и стопа в одной свече консервативно считается стопом. Это независимая оценка каждого сигнала, без комиссии, funding, проскальзывания и ограничений на параллельные позиции; она не прогнозирует будущую прибыльность.

## Личный список монет и ценовые уведомления

- `/watch BTCUSDT` добавляет USDT perpetual-контракт в список и ставит порог по умолчанию ±5% за 24 часа.
- `/watch BTCUSDT 3` задает собственный порог ±3%.
- `/watchlist` показывает список текущего чата; `/unwatch BTCUSDT` удаляет монету.
- Изменение проверяется раз в минуту по публичному тикеру Bybit. Повторные сообщения в том же направлении подавляются, пока изменение не вернется ниже 80% от порога; после этого новое пересечение порога снова создаст уведомление.
- В личном чате список принадлежит этому чату. Если добавить бота в группу, список и уведомления будут общими для группы.
